# P1 Mock Core Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `mock-core` (the shared deterministic mock-API library), the `world` binary that hosts mock services, and one example service (a GitHub Enterprise slice), all fully tested.

**Architecture:** A Rust workspace. `mock-core` holds one `WorldState` (logical clock, deterministic ID generators, an in-memory document store per service, an append-only journal) behind `Arc<Mutex<_>>`. Each mock service implements `MockService` and returns an axum `Router`; `mock-core` wraps it with a recording middleware that ticks the clock on mutating requests and journals every request/response. An admin app exposes health, journal, state, and reset. The `world` crate binds every service on its fixed port plus the admin port.

**Tech Stack:** Rust 2024 edition (toolchain 1.99), axum 0.8.9, tokio 1.54, serde/serde_json (with `preserve_order`), indexmap 2, time 0.3, toml 1.1, sha2 0.11, uuid 1.29 (v8), thiserror 2, anyhow 1; dev: tower 0.5 (`util`), reqwest 0.13, tempfile 3.27.

**Spec:** `docs/superpowers/specs/2026-10-30-tool-bench-design.md` (sections 3.2, 5.1–5.3, 9)

## Global Constraints

- No wall-clock reads, no randomness, no network egress anywhere in `mock-core` or services. Time comes only from `LogicalClock`; IDs only from dataset contents or `IdGen`.
- JSON output order follows insertion order (`serde_json` feature `preserve_order`); iteration over collections is insertion-ordered (`IndexMap`) and over services/collections is sorted (`BTreeMap`).
- Same scenario + same request sequence ⇒ byte-identical responses (spec 5.1 rule 1).
- Every request to a service is journaled (spec 5.1 rule 4).
- Admin endpoints live only on the admin port `9000`; the GitHub example listens on `8101`.
- Scenario source layout: `scenarios/<group>/<service-or-multi>/<id>/scenario.toml` + `dataset/<service>/<collection>.json` (spec 6.1). Dataset files are JSON arrays; a document's key is its `_key` field (removed on load) or else its `id`.
- `cargo fmt --check` and `cargo clippy --workspace --all-targets -- -D warnings` must pass at the end of every task.

```rust
use time::{OffsetDateTime, UtcOffset, format_description::well_known::Rfc3339};

use crate::error::{Error, Result};

/// Scenario time. Starts at the scenario's `now` and moves only when [`LogicalClock::tick`]
/// is called (once per mutating request), so timestamps never depend on the wall clock.
#[derive(Debug, Clone)]
pub struct LogicalClock {
    start: i64,
    step_secs: i64,
    ticks: i64,
}

impl LogicalClock {
    pub const DEFAULT_STEP_SECS: i64 = 7;

    pub fn new(start_rfc3339: &str, step_secs: i64) -> Result<Self> {
        let start = OffsetDateTime::parse(start_rfc3339, &Rfc3339)
            .map_err(|source| Error::Timestamp {
                value: start_rfc3339.to_owned(),
                source,
            })?
            .unix_timestamp();
        Ok(Self {
            start,
            step_secs,
            ticks: 0,
        })
    }

    pub fn now_unix(&self) -> i64 {
        self.start + self.ticks * self.step_secs
    }

    pub fn now_rfc3339(&self) -> String {
        format_unix(self.now_unix())
    }

    /// Advances one step and returns the new time.
    pub fn tick(&mut self) -> i64 {
        self.ticks += 1;
        self.now_unix()
    }
}

/// Formats a unix timestamp as second-precision RFC 3339 UTC, e.g. `2026-03-14T09:00:00Z`.
pub fn format_unix(secs: i64) -> String {
    OffsetDateTime::from_unix_timestamp(secs)
        .expect("timestamp within supported range")
        .to_offset(UtcOffset::UTC)
        .format(&Rfc3339)
        .expect("RFC 3339 formatting of a UTC timestamp")
}
```

```rust
use std::collections::BTreeMap;

use sha2::{Digest, Sha256};

const BASE62: &[u8; 62] = b"0123456789ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz";

/// Deterministic ID source for one service in one scenario.
#[derive(Debug, Clone)]
pub struct IdGen {
    seed: String,
    counters: BTreeMap<String, u64>,
}

impl IdGen {
    pub fn new(seed: impl Into<String>) -> Self {
        Self {
            seed: seed.into(),
            counters: BTreeMap::new(),
        }
    }

    fn bump(&mut self, kind: &str) -> u64 {
        let counter = self.counters.entry(kind.to_owned()).or_insert(0);
        let n = *counter;
        *counter += 1;
        n
    }

    fn digest(&self, kind: &str, n: u64, block: u64) -> [u8; 32] {
        let mut hasher = Sha256::new();
        hasher.update(self.seed.as_bytes());
        hasher.update([0]);
        hasher.update(kind.as_bytes());
        hasher.update([0]);
        hasher.update(n.to_be_bytes());
        hasher.update(block.to_be_bytes());
        let mut out = [0u8; 32];
        out.copy_from_slice(&hasher.finalize());
        out
    }

    /// `start`, `start + 1`, ... across calls with the same `kind`.
    pub fn next_int(&mut self, kind: &str, start: u64) -> u64 {
        start + self.bump(kind)
    }

    /// `prefix` followed by `len` base62 characters, e.g. `cus_` + 14 characters.
    pub fn next_prefixed(&mut self, kind: &str, prefix: &str, len: usize) -> String {
        let n = self.bump(kind);
        let mut out = String::with_capacity(prefix.len() + len);
        out.push_str(prefix);
        let mut block = 0;
        while out.len() < prefix.len() + len {
            for byte in self.digest(kind, n, block) {
                if out.len() == prefix.len() + len {
                    break;
                }
                out.push(BASE62[usize::from(byte) % BASE62.len()] as char);
            }
            block += 1;
        }
        out
    }

    /// RFC 9562 version 8 UUID derived from the seed, kind and counter.
    pub fn next_uuid(&mut self, kind: &str) -> uuid::Uuid {
        let n = self.bump(kind);
        let mut bytes = [0u8; 16];
        bytes.copy_from_slice(&self.digest(kind, n, 0)[..16]);
        uuid::Uuid::new_v8(bytes)
    }
}
```

```rust
use std::collections::BTreeMap;

use indexmap::IndexMap;
use serde_json::{Map, Value};

/// Named JSON documents in insertion order.
#[derive(Debug, Clone, Default)]
pub struct Collection {
    docs: IndexMap<String, Value>,
}

impl Collection {
    pub fn insert(&mut self, key: impl Into<String>, doc: Value) -> Option<Value> {
        self.docs.insert(key.into(), doc)
    }

    pub fn get(&self, key: &str) -> Option<&Value> {
        self.docs.get(key)
    }

    pub fn get_mut(&mut self, key: &str) -> Option<&mut Value> {
        self.docs.get_mut(key)
    }

    /// Removes a document, keeping the order of the rest.
    pub fn remove(&mut self, key: &str) -> Option<Value> {
        self.docs.shift_remove(key)
    }

    pub fn contains(&self, key: &str) -> bool {
        self.docs.contains_key(key)
    }

    pub fn len(&self) -> usize {
        self.docs.len()
    }

    pub fn is_empty(&self) -> bool {
        self.docs.is_empty()
    }

    pub fn iter(&self) -> impl Iterator<Item = (&str, &Value)> {
        self.docs.iter().map(|(k, v)| (k.as_str(), v))
    }

    pub fn values(&self) -> impl Iterator<Item = &Value> {
        self.docs.values()
    }
}

/// All collections of one service.
#[derive(Debug, Clone, Default)]
pub struct Store {
    collections: BTreeMap<String, Collection>,
}

impl Store {
    pub fn collection(&self, name: &str) -> Option<&Collection> {
        self.collections.get(name)
    }

    pub fn collection_mut(&mut self, name: &str) -> &mut Collection {
        self.collections.entry(name.to_owned()).or_default()
    }

    /// `{ "<collection>": { "<key>": doc, ... }, ... }`, collections sorted by name.
    pub fn snapshot(&self) -> Value {
        let mut out = Map::new();
        for (name, collection) in &self.collections {
            let docs = collection
                .iter()
                .map(|(k, v)| (k.to_owned(), v.clone()))
                .collect::<Map<_, _>>();
            out.insert(name.clone(), Value::Object(docs));
        }
        Value::Object(out)
    }
}
```

```rust
use std::{
    collections::BTreeMap,
    fs,
    path::{Path, PathBuf},
};

use serde::Deserialize;
use serde_json::Value;

use crate::{
    clock::LogicalClock,
    error::{Error, Result},
    store::{Collection, Store},
};

/// The `[scenario]` table of `scenario.toml`. Other tables are ignored here.
#[derive(Debug, Clone, Deserialize)]
pub struct ScenarioMeta {
    pub id: String,
    pub now: String,
    pub seed: String,
    #[serde(default = "default_step")]
    pub clock_step_secs: i64,
}

fn default_step() -> i64 {
    LogicalClock::DEFAULT_STEP_SECS
}

#[derive(Deserialize)]
struct ScenarioFile {
    scenario: ScenarioMeta,
}

/// A scenario's starting world: metadata plus one store per service directory.
#[derive(Debug, Clone)]
pub struct Dataset {
    pub meta: ScenarioMeta,
    pub services: BTreeMap<String, Store>,
}

impl Dataset {
    /// Loads `<root>/scenario.toml` and every `<root>/dataset/<service>/<collection>.json`.
    pub fn load(root: &Path) -> Result<Self> {
        let meta_path = root.join("scenario.toml");
        let file: ScenarioFile = toml::from_str(&read(&meta_path)?).map_err(|e| Error::Parse {
            path: meta_path.clone(),
            message: e.to_string(),
        })?;

        let mut services = BTreeMap::new();
        let data_dir = root.join("dataset");
        if data_dir.is_dir() {
            for service_dir in sorted_entries(&data_dir)? {
                if !service_dir.is_dir() {
                    continue;
                }
                let mut store = Store::default();
                for file in sorted_entries(&service_dir)? {
                    if file.extension().is_some_and(|ext| ext == "json") {
                        let name = file_stem(&file);
                        load_collection(&file, store.collection_mut(&name))?;
                    }
                }
                services.insert(file_stem(&service_dir), store);
            }
        }

        Ok(Self {
            meta: file.scenario,
            services,
        })
    }
}

fn load_collection(path: &Path, collection: &mut Collection) -> Result<()> {
    let value: Value = serde_json::from_str(&read(path)?).map_err(|e| Error::Parse {
        path: path.to_owned(),
        message: e.to_string(),
    })?;
    let Value::Array(docs) = value else {
        return Err(dataset_error(path, "expected a JSON array of documents".to_owned()));
    };
    for (index, mut doc) in docs.into_iter().enumerate() {
        let key = document_key(&mut doc)
            .ok_or_else(|| dataset_error(path, format!("document {index} has no \"_key\" or \"id\"")))?;
        if collection.insert(key.clone(), doc).is_some() {
            return Err(dataset_error(path, format!("duplicate key {key:?}")));
        }
    }
    Ok(())
}

/// `_key` (removed from the document) wins; otherwise the `id` field as a string.
fn document_key(doc: &mut Value) -> Option<String> {
    let obj = doc.as_object_mut()?;
    if let Some(key) = obj.shift_remove("_key") {
        return Some(match key {
            Value::String(s) => s,
            other => other.to_string(),
        });
    }
    match obj.get("id")? {
        Value::String(s) => Some(s.clone()),
        Value::Number(n) => Some(n.to_string()),
        _ => None,
    }
}

fn read(path: &Path) -> Result<String> {
    fs::read_to_string(path).map_err(|source| Error::Io {
        path: path.to_owned(),
        source,
    })
}

fn sorted_entries(dir: &Path) -> Result<Vec<PathBuf>> {
    let io = |source| Error::Io {
        path: dir.to_owned(),
        source,
    };
    let mut paths = fs::read_dir(dir)
        .map_err(io)?
        .map(|entry| entry.map(|e| e.path()))
        .collect::<std::io::Result<Vec<_>>>()
        .map_err(io)?;
    paths.sort();
    Ok(paths)
}

fn file_stem(path: &Path) -> String {
    path.file_stem()
        .map(|s| s.to_string_lossy().into_owned())
        .unwrap_or_default()
}

fn dataset_error(path: &Path, message: String) -> Error {
    Error::Dataset {
        path: path.to_owned(),
        message,
    }
}
```

```rust
use serde::Serialize;
use serde_json::Value;

/// One request/response pair as seen by the world.
#[derive(Debug, Clone, PartialEq, Serialize)]
pub struct JournalEntry {
    pub seq: u64,
    /// Logical time after any tick caused by this request.
    pub time: String,
    pub service: String,
    /// Peer IP of the caller; used to detect requests that bypassed the MCP servers.
    pub source: String,
    pub method: String,
    pub path: String,
    pub query: Option<String>,
    pub request_body: Value,
    pub status: u16,
    pub response_body: Value,
}

/// Append-only, ordered record of every request served.
#[derive(Debug, Clone, Default)]
pub struct Journal {
    entries: Vec<JournalEntry>,
}

impl Journal {
    pub fn next_seq(&self) -> u64 {
        self.entries.len() as u64 + 1
    }

    pub fn push(&mut self, entry: JournalEntry) {
        assert_eq!(entry.seq, self.next_seq(), "journal sequence must be contiguous");
        self.entries.push(entry);
    }

    pub fn entries(&self) -> &[JournalEntry] {
        &self.entries
    }
}

/// `null` for an empty body, parsed JSON when possible, otherwise the text.
pub fn body_value(bytes: &[u8]) -> Value {
    if bytes.is_empty() {
        return Value::Null;
    }
    serde_json::from_slice(bytes).unwrap_or_else(|_| Value::String(String::from_utf8_lossy(bytes).into_owned()))
}
```

```rust
use std::{
    collections::BTreeMap,
    sync::{Arc, Mutex},
};

use serde_json::{Map, Value, json};

use crate::{
    clock::LogicalClock,
    dataset::{Dataset, ScenarioMeta},
    error::Result,
    ids::IdGen,
    journal::Journal,
    store::Store,
};

/// Mutable state of one mock service.
#[derive(Debug, Clone)]
pub struct ServiceState {
    pub store: Store,
    pub ids: IdGen,
}

/// Everything a running world knows. Exactly one scenario per world.
#[derive(Debug, Clone)]
pub struct WorldState {
    pub meta: ScenarioMeta,
    pub clock: LogicalClock,
    pub journal: Journal,
    services: BTreeMap<String, ServiceState>,
    source: Dataset,
}

pub type SharedWorld = Arc<Mutex<WorldState>>;

pub fn shared(state: WorldState) -> SharedWorld {
    Arc::new(Mutex::new(state))
}

impl WorldState {
    pub fn from_dataset(dataset: Dataset) -> Result<Self> {
        let meta = dataset.meta.clone();
        let clock = LogicalClock::new(&meta.now, meta.clock_step_secs)?;
        let services = dataset
            .services
            .iter()
            .map(|(name, store)| {
                let state = ServiceState {
                    store: store.clone(),
                    ids: IdGen::new(service_seed(&meta.seed, name)),
                };
                (name.clone(), state)
            })
            .collect();
        Ok(Self {
            meta,
            clock,
            journal: Journal::default(),
            services,
            source: dataset,
        })
    }

    pub fn service(&self, name: &str) -> Option<&ServiceState> {
        self.services.get(name)
    }

    /// The named service's state, created empty if the dataset had none.
    pub fn service_mut(&mut self, name: &str) -> &mut ServiceState {
        let seed = service_seed(&self.meta.seed, name);
        self.services
            .entry(name.to_owned())
            .or_insert_with(|| ServiceState {
                store: Store::default(),
                ids: IdGen::new(seed),
            })
    }

    /// Back to the scenario's starting state: dataset, clock, IDs, and an empty journal.
    pub fn reset(&mut self) {
        *self = Self::from_dataset(self.source.clone()).expect("dataset was valid when first loaded");
    }

    pub fn snapshot(&self) -> Value {
        let services = self
            .services
            .iter()
            .map(|(name, state)| (name.clone(), state.store.snapshot()))
            .collect::<Map<_, _>>();
        json!({
            "scenario": self.meta.id,
            "now": self.clock.now_rfc3339(),
            "services": services,
        })
    }
}

fn service_seed(seed: &str, service: &str) -> String {
    format!("{seed}/{service}")
}
```

```rust
/// JSON response with the given status. Field order follows the `Value`.
pub fn json(status: StatusCode, body: Value) -> Response {
    with_content_type(status, "application/json; charset=utf-8", body)
}

/// JSON:API response (used by HCP Terraform).
pub fn jsonapi(status: StatusCode, body: Value) -> Response {
    with_content_type(status, "application/vnd.api+json", body)
}

fn with_content_type(status: StatusCode, content_type: &'static str, body: Value) -> Response {
    (status, [(CONTENT_TYPE, content_type)], body.to_string()).into_response()
}

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct PageParams {
    pub page: usize,
    pub per_page: usize,
}

impl PageParams {
    /// Parses `page`/`per_page` query values. Unparseable values fall back to defaults;
    /// `page` is at least 1 and `per_page` is clamped to `1..=max_per_page`.
    pub fn parse(page: Option<&str>, per_page: Option<&str>, default_per_page: usize, max_per_page: usize) -> Self {
        let page = page.and_then(|p| p.parse::<usize>().ok()).unwrap_or(1).max(1);
        let per_page = per_page
            .and_then(|p| p.parse::<usize>().ok())
            .unwrap_or(default_per_page)
            .clamp(1, max_per_page);
        Self { page, per_page }
    }
}

pub fn paginate<T: Clone>(items: &[T], params: PageParams) -> Vec<T> {
    items
        .iter()
        .skip((params.page - 1) * params.per_page)
        .take(params.per_page)
        .cloned()
        .collect()
}

/// RFC 8288 `Link` header in GitHub's order (prev, next, last, first), or `None` for a single page.
pub fn link_header(url_without_paging: &str, params: PageParams, total: usize) -> Option<String> {
    let last = total.div_ceil(params.per_page).max(1);
    let sep = if url_without_paging.contains('?') { '&' } else { '?' };
    let link = |page: usize, rel: &str| {
        format!("<{url_without_paging}{sep}page={page}&per_page={}>; rel=\"{rel}\"", params.per_page)
    };
    let mut rels = Vec::new();
    if params.page > 1 {
        rels.push(link(params.page - 1, "prev"));
    }
    if params.page < last {
        rels.push(link(params.page + 1, "next"));
        rels.push(link(last, "last"));
    }
    if params.page > 1 {
        rels.push(link(1, "first"));
    }
    (!rels.is_empty()).then(|| rels.join(", "))
}
```

```rust
use std::net::SocketAddr;

use axum::{
    Router,
    body::{Body, to_bytes},
    extract::{ConnectInfo, Request, State},
    http::{Method, StatusCode},
    middleware::{self, Next},
    response::{IntoResponse, Response},
};
use tokio::net::TcpListener;

use crate::{
    journal::{JournalEntry, body_value},
    service::MockService,
    world::SharedWorld,
};

const MAX_BODY_BYTES: usize = 32 * 1024 * 1024;

#[derive(Clone)]
struct Recorder {
    world: SharedWorld,
    service: &'static str,
}

/// The service's router with clock ticking and journaling applied, bound to `world`.
pub fn service_app(world: SharedWorld, service: &dyn MockService) -> Router {
    let recorder = Recorder {
        world: world.clone(),
        service: service.name(),
    };
    service
        .router()
        .layer(middleware::from_fn_with_state(recorder, record))
        .with_state(world)
}

/// Serves `app`, attaching the caller's address to each request for the journal.
pub async fn serve(listener: TcpListener, app: Router) -> std::io::Result<()> {
    axum::serve(listener, app.into_make_service_with_connect_info::<SocketAddr>()).await
}

async fn record(State(recorder): State<Recorder>, request: Request, next: Next) -> Response {
    let (parts, body) = request.into_parts();
    let Ok(request_bytes) = to_bytes(body, MAX_BODY_BYTES).await else {
        return StatusCode::PAYLOAD_TOO_LARGE.into_response();
    };
    let method = parts.method.clone();
    let path = parts.uri.path().to_owned();
    let query = parts.uri.query().map(str::to_owned);
    let source = parts
        .extensions
        .get::<ConnectInfo<SocketAddr>>()
        .map(|info| info.0.ip().to_string())
        .unwrap_or_else(|| "unknown".to_owned());

    if is_mutating(&method) {
        recorder.world.lock().expect("world lock").clock.tick();
    }

    let response = next.run(Request::from_parts(parts, Body::from(request_bytes.clone()))).await;
    let (response_parts, response_body) = response.into_parts();
    let response_bytes = to_bytes(response_body, MAX_BODY_BYTES).await.unwrap_or_default();

    {
        let mut world = recorder.world.lock().expect("world lock");
        let entry = JournalEntry {
            seq: world.journal.next_seq(),
            time: world.clock.now_rfc3339(),
            service: recorder.service.to_owned(),
            source,
            method: method.to_string(),
            path,
            query,
            request_body: body_value(&request_bytes),
            status: response_parts.status.as_u16(),
            response_body: body_value(&response_bytes),
        };
        world.journal.push(entry);
    }

    Response::from_parts(response_parts, Body::from(response_bytes))
}

fn is_mutating(method: &Method) -> bool {
    !matches!(*method, Method::GET | Method::HEAD | Method::OPTIONS)
}
```

```rust
//! with `GITHUB_HOST` pointed at the world. P1 example slice; the full surface lands in P4.

use std::collections::HashMap;

use axum::{
    Router,
    body::Bytes,
    extract::{Path, Query, State},
    http::{HeaderMap, HeaderValue, StatusCode, header},
    response::Response,
    routing::get,

    http::{PageParams, json, link_header, paginate},
    service::MockService,
    world::SharedWorld,
};
use serde_json::{Value, json as json_value};

pub const NAME: &str = "github";
pub const PORT: u16 = 8101;

const VIEWER_SUMMARY_FIELDS: [&str; 8] = ["login", "id", "node_id", "avatar_url", "url", "html_url", "type", "site_admin"];

pub struct GitHub;

impl MockService for GitHub {
    fn name(&self) -> &'static str {

    fn port(&self) -> u16 {

async fn get_viewer(State(world): State<SharedWorld>) -> Response {
    let world = world.lock().expect("world lock");
    match world.service(NAME).and_then(|s| s.store.collection("viewer")).and_then(|c| c.get("viewer")) {

    }

async fn list_issues(
    State(world): State<SharedWorld>,
    Path((owner, repo)): Path<(String, String)>,
    Query(query): Query<HashMap<String, String>>,
    headers: HeaderMap,
) -> Response {
    let full_name = format!("{owner}/{repo}");
    let world = world.lock().expect("world lock");
    let Some(service) = world.service(NAME) else {
        return not_found();
    };
    if !service.store.collection("repos").is_some_and(|c| c.contains(&full_name)) {
        return not_found();
    }

    let state = query.get("state").map_or("open", String::as_str);
    let prefix = format!("{full_name}#");
    let mut issues: Vec<Value> = service
        .store
        .collection("issues")
        .map(|c| {
            c.iter()
                .filter(|(key, issue)| key.starts_with(&prefix) && (state == "all" || issue["state"] == state))
                .map(|(_, issue)| issue.clone())
                .collect()
        })
        .unwrap_or_default();
    issues.sort_by_key(|issue| std::cmp::Reverse(issue["number"].as_u64()));

    let params = PageParams::parse(query.get("page").map(String::as_str), query.get("per_page").map(String::as_str), 30, 100);
    let mut response = json(StatusCode::OK, Value::Array(paginate(&issues, params)));
    let base = format!("{}/api/v3/repos/{full_name}/issues?state={state}", base_url(&headers));
    if let Some(link) = link_header(&base, params, issues.len()) {
        response
            .headers_mut()
            .insert(header::LINK, HeaderValue::from_str(&link).expect("link header is ASCII"));
    }
    response
}

async fn create_issue(
    State(world): State<SharedWorld>,
    Path((owner, repo)): Path<(String, String)>,
    headers: HeaderMap,
    body: Bytes,
) -> Response {
    let Ok(input) = serde_json::from_slice::<Value>(&body) else {
        return json(StatusCode::BAD_REQUEST, github_error("Problems parsing JSON"));
    };
    let full_name = format!("{owner}/{repo}");
    let mut guard = world.lock().expect("world lock");
    let world = &mut *guard;
    let now = world.clock.now_rfc3339();
    let service = world.service_mut(NAME);
    if !service.store.collection("repos").is_some_and(|c| c.contains(&full_name)) {
        return not_found();
    }
    let Some(title) = input.get("title").and_then(Value::as_str) else {
        return json(StatusCode::UNPROCESSABLE_ENTITY, github_error("Invalid request.\n\n\"title\" wasn't supplied."));
    };

    let prefix = format!("{full_name}#");
    let issues = service.store.collection("issues");
    let number = issues
        .map(|c| c.iter().filter(|(k, _)| k.starts_with(&prefix)).filter_map(|(_, v)| v["number"].as_u64()).max().unwrap_or(0))
        .unwrap_or(0)
        + 1;
    let id = issues.map(|c| c.values().filter_map(|v| v["id"].as_u64()).max().unwrap_or(0)).unwrap_or(0) + 1;
    let user = service
        .store
        .collection("viewer")
        .and_then(|c| c.get("viewer"))
        .map(viewer_summary)
        .unwrap_or(Value::Null);
    let node_id = service.ids.next_prefixed("issue_node", "I_kwDO", 16);

    let base = base_url(&headers);
    let url = format!("{base}/api/v3/repos/{full_name}/issues/{number}");
    let issue = json_value!({
        "url": url,
        "repository_url": format!("{base}/api/v3/repos/{full_name}"),
        "html_url": format!("{base}/{full_name}/issues/{number}"),
        "id": id,
        "node_id": node_id,
        "number": number,
        "title": title,
        "user": user,
        "labels": [],
        "state": "open",
        "locked": false,
        "assignee": null,
        "assignees": [],
        "milestone": null,
        "comments": 0,
        "created_at": now,
        "updated_at": now,
        "closed_at": null,
        "author_association": "OWNER",
        "body": input.get("body").cloned().unwrap_or(Value::Null),
    });
    service.store.collection_mut("issues").insert(format!("{prefix}{number}"), issue.clone());

    let mut response = json(StatusCode::CREATED, issue);
    response
        .headers_mut()
        .insert(header::LOCATION, HeaderValue::from_str(&url).expect("URL is ASCII"));
    response
}

fn viewer_summary(viewer: &Value) -> Value {
    let mut summary = serde_json::Map::new();
    for field in VIEWER_SUMMARY_FIELDS {
        if let Some(value) = viewer.get(field) {
            summary.insert(field.to_owned(), value.clone());
        }
    }
    Value::Object(summary)
}

fn base_url(headers: &HeaderMap) -> String {
    let scheme = headers.get("x-forwarded-proto").and_then(|v| v.to_str().ok()).unwrap_or("http");
    let host = headers.get(header::HOST).and_then(|v| v.to_str().ok()).unwrap_or("localhost");
    format!("{scheme}://{host}")
}

fn github_error(message: &str) -> Value {
    json_value!({ "message": message, "documentation_url": "https://docs.github.com/rest" })
}

fn not_found() -> Response {
    json(
        StatusCode::NOT_FOUND,
        json_value!({ "message": "Not Found", "documentation_url": "https://docs.github.com/rest", "status": "404" }),
    )
}
```

```rust
//! Hosts every mock service plus the admin API for one scenario.

use std::{
    collections::BTreeMap,
    io,
    net::{IpAddr, SocketAddr},
};

use mock_core::{
    admin::admin_app,
    serve::{serve, service_app},
    service::MockService,
    world::SharedWorld,
};
use tokio::{net::TcpListener, task::JoinSet};

pub const ADMIN_PORT: u16 = 9000;

/// Every mock service compiled into the world.
pub fn services() -> Vec<Box<dyn MockService>> {
    vec![Box::new(mock_github::GitHub)]
}

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum PortChoice {
    /// Each service on its own fixed port, admin on [`ADMIN_PORT`] (container use).
    Fixed,
    /// OS-assigned ports (tests).
    Ephemeral,
}

pub struct Running {
    pub admin: SocketAddr,
    pub services: BTreeMap<&'static str, SocketAddr>,
    tasks: JoinSet<io::Result<()>>,
}

impl Running {
    /// Runs until any listener stops, returning its error.
    pub async fn wait(mut self) -> io::Result<()> {
        while let Some(result) = self.tasks.join_next().await {
            result.map_err(io::Error::other)??;
        }
        Ok(())
    }
}

/// Binds the admin API and every service, then serves them in the background.
pub async fn spawn(world: SharedWorld, ip: IpAddr, ports: PortChoice) -> io::Result<Running> {
    let port = |fixed: u16| match ports {
        PortChoice::Fixed => fixed,
        PortChoice::Ephemeral => 0,
    };
    let mut tasks = JoinSet::new();

    let admin_listener = TcpListener::bind((ip, port(ADMIN_PORT))).await?;
    let admin = admin_listener.local_addr()?;
    tasks.spawn(serve(admin_listener, admin_app(world.clone())));

    let mut bound = BTreeMap::new();
    for service in services() {
        let listener = TcpListener::bind((ip, port(service.port()))).await?;
        bound.insert(service.name(), listener.local_addr()?);
        tasks.spawn(serve(listener, service_app(world.clone(), service.as_ref())));
    }

    Ok(Running {
        admin,
        services: bound,
        tasks,
    })
}
```
