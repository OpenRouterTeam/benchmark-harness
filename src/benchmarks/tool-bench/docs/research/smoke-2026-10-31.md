# Model smoke run (2026-10-31)

`deploy/smoke-ori.sh` ran Claude Code 2.1.310 through `ori claude` on the host, using
`anthropic/claude-haiku-5.5` on OpenRouter. It saw only the 32 benchmark MCP servers (fresh
`CLAUDE_CONFIG_DIR`, `--strict-mcp-config`). The world and tools ran in Docker from the merged
`main`. Grading used `/_bench/grade` with each task's `expect.json`.

All six trials had `mcp_bypass = 0`, and all 32 servers connected each time.

## Findings

- **Claude Code defers large tool sets by default.** With 1,594 MCP tools it exposes `ToolSearch`
  and loads tools on demand, so the full payload never reaches the endpoint. To measure a
  router's own handling of the full list, turn deferral off with `ENABLE_TOOL_SEARCH=false`
  (`MODE=full`). That is the spec's `full-payload` profile (section 8).
- **Full payload is about 820k Claude tokens per turn.** That is more than the o200k
  estimate of 727k. It fits 1M-context models; models under about 820k fail at the first turn,
  which the grader records as `context_overflow`.
- **Visible tools: 1,594 of 1,595.** GitHub's `ui_get` is marked `_meta.ui.visibility: ["app"]`,
  so Claude Code hides it from the model, which is correct.
- **Bug found and fixed:** Claude Code dropped all 10 Stripe tools because the replica schemas
  lacked a top-level `"type": "object"`. The capture source stores function parameters without it.
  The snapshot now has it, and the schema lint shows no other endpoint missing it.
- **Startup calls count toward `api_calls`.** The 33–63 world requests per trial include each MCP
  server's startup handshake. `required_calls` and `forbidden_calls` are unaffected; read
  `api_calls` as a relative measure only.
- **Version:** these runs used the host's Claude Code (2.1.310), not the 2.1.235 pin. Harbor runs
  pin the harness with `--ak version=…`.
