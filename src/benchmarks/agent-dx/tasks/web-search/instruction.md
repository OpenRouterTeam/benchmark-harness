Build a minimal TypeScript Node project in the current directory that answers a current-events question with up-to-date information from the web, using OpenRouter's web search capability so the answer includes citations to its sources.

The API key is in the OPENROUTER_API_KEY environment variable. `npm start` should ask "What are the most notable AI model releases this month?", print the raw API response as JSON, and then print the answer with the source URLs it cited.
