# Deferred-tools arms, 2026-10-31

`deploy/smoke-arms.sh` runs one task under one arm; `deploy/tally-arms.py` tallies a results directory per model. 18 stratified tasks (two single-service and one cross-service task from each of the 6 groups) × 3 attempts × 3 arms, Claude Code with all 32 MCP endpoints (1,618 tools) attached, providers pinned.

- `universal`: `ENABLE_TOOL_SEARCH=false`; `deploy/arm-proxy.ts --universal` adds `deferred_tools {protocol: v1, profile: universal, validation: runtime, search: bm25, max_results 8}` and routes to a local router running the universal profile.
- `native`: Claude Code's own client-side ToolSearch (`ENABLE_TOOL_SEARCH=true`).
- `off`: every tool sent upfront (`ENABLE_TOOL_SEARCH=false`).

Paired differences are per-task means with a seeded bootstrap (20261031), 95% intervals.

## Notes

- 7 runs hit a local DNS outage and were rerun; one `off` run missing a server after a hung catalog lookup was rerun.
- The world's `context_overflow` outcome never fires locally (MCP startup handshakes make the tools journal non-empty), so `tally-arms.py` derives overflow from the harness's context-length error plus zero tool uses.
